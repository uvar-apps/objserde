# Sample meshes

Three test assets with deliberately different characteristics, so the loader
and rasterizer are exercised on more than one kind of file.

## stanford-bunny.obj

Stanford bunny (scan-decimated: ~69k triangles). Downloaded from Alec
Jacobson's [common-3d-test-models](https://github.com/alecjacobson/common-3d-test-models)
(`data/stanford-bunny.obj`), which mirrors the Stanford 3D Scanning Repository
data; original by Greg Turk and Marc Levoy.

- Positions and faces only — **no `vn`, no `vt`**. Exercises the
  geometric-normal fallback path and edge-on slivers.
- Scan data, so not manifold everywhere and not watertight. A viewer must
  still render it without artifacts.
- Units are roughly ±0.1 (not ångströms); use a zoom around 2500 to fill the
  frame.

## xyzrgb_dragon.obj

Stanford XYZRGB dragon (~125k vertices / ~250k triangles), from the same
repository, original by the Stanford graphics group (Turk/Levoy scan data).

- Positions and faces only, no normals.
- The large stress-test mesh. Units ±25; zoom ~20 fills the frame.

## 1crn_ses_0.5A.obj

Solvent-excluded surface of crambin (PDB entry 1CRN, RCSB — free for all uses),
generated by [molses](https://github.com/uvar-apps/molses) v0.2.0:

```sh
molses 1crn.pdb -o 1crn_ses_0.5A.obj --grid-spacing 0.5 --all-components --force
```

- 37,930 vertices / 75,852 triangles with per-vertex normals, written in
  `f i//i` form — exercises the `vn` binding path.
- Watertight, closed, Euler characteristic 4; coordinates in ångströms
  (bbox spans ~35 Å). Zoom ~30 for the whole protein; `--zoom 110 --focus
  4.29,5.05,4.55` frames the crevice region this mesh family is inspected for.
